# OnboardAI Architecture

This repository records the team's decisions about what OnboardAI will do and how it will be built.

## Decision workshop

Work through the files in [`decisions/`](decisions/00-index.md) in order. For each question, discuss the options and write the team's answer. An unanswered question remains open; do not fill it with an assumption.

The questions are prompts, not approved requirements or technology choices. Record significant architecture choices separately in [`adr/`](adr/README.md), then update the [system map](decisions/13-system-map.md) and place editable diagrams in [`visuals/`](visuals/README.md).

For each answer, note whether it applies to the prototype, a later version, or both. If evidence is missing, record the test or research needed and an owner.
