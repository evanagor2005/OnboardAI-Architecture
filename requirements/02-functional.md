# Functional requirements

What externally observable capabilities are needed for each accepted use case? Separate required prototype behavior from future ideas.

## Capability questions

- What shall a user be able to start, complete, resume, or review?
- What shall the system return when it succeeds, lacks evidence, or encounters an error?
- What shall administrators or knowledge owners be able to change?
- What shall an approved AI assistant be able to request, if included?
- What shall the system record about progress or feedback, if included?
